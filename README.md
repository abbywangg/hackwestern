# flow.state | Bio-Canvas

A biometric-driven creative workspace that visualizes flow states in real-time.

## Overview

flow.state is a web application that combines biometric data with creative tools to help users optimize their creative process. The app visualizes your heart rate as a dynamic "flow orb" and provides AI-powered insights to enhance productivity.

## Features

- **Real-time Flow Visualization**: Dynamic orb that changes color based on heart rate (60-110 BPM range)
- **Interactive Canvas**: Drag-and-drop note system with color-coded organization
- **AI Insights**: Gemini API integration for creative suggestions and breathing techniques
- **Timer System**: Stopwatch and countdown timer modes
- **Flow Analytics**: Track session history and flow DNA patterns

## Getting Started

### Running the Frontend

1. Navigate to the `frontend-web` folder
2. Open `main.html` in a web browser

### Tech Stack

- React 18 (via CDN)
- Tailwind CSS (via CDN)
- Google Gemini AI API
- Vanilla JavaScript/HTML/CSS
